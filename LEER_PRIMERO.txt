CORRECCIÓN: GITHUB MUESTRA LAS INSTRUCCIONES EN VEZ DEL PORTAL

1. Extrae este ZIP.
2. En tu repositorio mesa-de-partes, sube el contenido extraído. index.html debe estar junto a README.md, no dentro de otra carpeta.
3. Conserva la carpeta docs con sus archivos, imágenes y configuración Firebase.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Espera a que GitHub termine de publicar y actualiza con Ctrl+F5.

El nuevo index.html abre el portal automáticamente. No necesitas cambiar Firebase para corregir la portada. Para registrar y gestionar expedientes, deben seguir activados los servicios y las reglas descritos en README.md.
